2.  How to Navigate to contact and related cases.

 

Ø  To navigate contact move on sitemap and click on contacts.

 

Ø  Active contact default view will open. User can switch view from arrow.

Ø  Open Active view and user can search contact on the basis of below Field value. User can type value and search related details. For example, Full Name, Last Name, Email id etc.

 

Ø  User can open each tab and find relevant details as well.

Summary

In summary tab user can view personal information of customer, customer address, communication details and timeline section contain activity related to the customer.

·         Update Personal Information

Ø  Open contact record which needs to be update

Ø  Click directly into the field and make necessary modifications

Ø  Once updated, click ‘Save’ or ‘Save & Close’ button.

 

Details

In details tab user can view personal details (Number of cards), also contain Payment information, Profile Medical Requirements etc.

 

Communication Details - Communication details tab contains information about customer email addresses, phone number and information related to the preferences

·         Update Email

Ø  Select the email address which we want to update

Ø  Click edit button

Ø  Update the specific field and then click on save and close button

         

  • Create New Email

Ø  To create new email, click on ‘New Profile email button

Ø  Quick Create : Profile email form will be open

Ø  Enter information in mandatory field and click on save & close button

              

 

Follow same process to create and update phone number details.

Ø  Update the specific field and then click on save and close button

 

    

  • Create New Preferences

3.  Creation of Contact

 

Creation of Contact

Ø  On site map click on Contact entity

Ø  Click on New contact button

Ø  Contact form should be open

Ø  Enter data in all the mandatory fields and click on save button

 

 

Creation of Loyalty contact

Ø  On site map click on Contact entity

Ø  Click on New contact button

Ø  Contact form should be open

Ø  Enter data in all the mandatory fields

Ø  Again, click on Loyalty section and marked Loyalty option as ‘Yes’

Ø  It will create Loyalty contact

 

4.  Navigate to Cases

 

3.1 How to navigate cases from contact.

Open contact and cases tab. User will find all related case to that contact in sub grid.

 

3.2 Cases

Ø  Click on cases on Sitemap. Default My Active view will open.

Ø  User can switch to All cases or Active cases. Or any view as per requirement.

 

Ø  User can search cases with case n., Case Title or Customer

 

3.3 Case Navigations

Overview

Agent can find case details, Complaint categories, Customer details, Booking details, Descriptions and more on overview tab.

Timeline

Agent can find all activity such as email communications, task, Posts and more on Timeline tab.

 

 

We can create different activity in timeline for ex. Task, email

Creation of email

Ø  Open one of the existing cases and click on timeline tab

Ø  Click on ‘+’ button and select email

Ø  Add subject and description, save the email

Ø  And click on send button

 

Incident

Agent can find incident details in this tab.

 

 

 

Flight Itinerary

5.Navigation to Queue

 

Ø  To navigate contact move on sitemap and click on Queue

 

Ø  Items I am working on default view will open. User can switch view from arrow.

 

Ø  Change the View to ‘Items available to worked on’

Ø  View contains all the records which are available to work

 

 

Ø  Queue will contain different view, and it will represent data as per selected view.
